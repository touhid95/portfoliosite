**Title:** Financial Market Predictive Analytics  
**Subtitle:** Portfolio Forecasting & Asset Optimization

A stock trend forecasting and risk simulation model based on Modern Portfolio Theory (MPT) principles. Fetches public financial data, runs Monte Carlo allocations, and exports core risk-return metrics.

### Key Contributions
- Automated streaming of ticker histories with Python `yfinance` API, performing daily data cleanses.
- Executed 5,000 portfolio simulation iterations, finding the optimal weights for the Sharpe Ratio.
- Crafted interactive dashboards displaying rolling standard deviations, beta values, and asset distributions.

### Technologies
`Python` · `Pandas` · `NumPy` · `Power BI` · `yfinance` · `Monte Carlo`

**Title:** Retail Sales Database Optimization  
**Subtitle:** Database Normalisation & Analytical Queries

An enterprise schema refactoring project designed to minimize storage redundancy and accelerate query times. Raw transaction files were modeled into Third Normal Form (3NF) tables.

### Key Contributions
- Structured a 3NF database layout supporting 200,000 purchase logs.
- Wrote query pipelines using SQL Common Table Expressions (CTEs), Subqueries, and Window Functions.
- Designed retail performance boards mapped onto geographic areas with Tableau heatmaps.

### Technologies
`SQL Server` · `3NF Design` · `Window Functions` · `CTEs` · `Tableau`


**Title:** Customer Segmentation & RFM Analysis  
**Subtitle:** Unsupervised Machine Learning & Segment Analysis

An analytical approach to segmenting retail store buyers using historical activity (Recency, Frequency, Monetary). By grouping buyers, businesses can tailor their retention campaigns.

### Key Contributions
- Engineered cohort RFM scores from high-volume transactional audit files.
- Applied KMeans clustering algorithms, evaluating clusters via the Elbow method and Silhouette analysis.
- Profiled buyer segments, producing customized activation advice for the marketing division.

### Technologies
`Python` · `Scikit-Learn` · `Pandas` · `KMeans Clustering` · `RFM Modeling` · `Seaborn`
